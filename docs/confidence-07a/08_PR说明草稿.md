## 3. 提交前检查

1. `deliverable/tests/__init__.py` **不要复制**。仓库根已有 06B 的 `tests/` 目录，加入 `__init__.py` 会改变 06B 测试的导入方式。已验证：去掉它后，`python -m unittest discover -s tests/confidence_07a -t .` 仍全部通过。
2. 不要用 `discover -s tests`（会把 06B 需要网络和密钥的测试一起收进来）；一律用 `-s tests/confidence_07a`。
3. 复制前先确认团队仓库根目录没有同名的 `gold/`、`tools/`、`artifacts/`（下面第 4 步会检查）。如果有，先和 PM 商量换目录名（例如 `gold_07a/`），不要覆盖。
4. CI 文件 `.github/workflows/confidence-07a.yml` 还没写。最小内容：路径过滤 `confidence_07a/**`、`tests/confidence_07a/**`、`gold/**`；Python 3.10 和 3.12；运行上面的 unittest 命令。
5. `artifacts/scorecards_v2/rule/` 约 1.7 MB（120 个文件）。如果 PM 不希望提交大量产物，只保留 `v1_vs_v2.md`、`summary.csv` 和 `artifacts/demo_g6/`。
6. 再搜一次密钥：确认要提交的文件里没有任何密钥样字符串，也没有 `.env`。
7. **不要**提交 `_claude_work/` 下的其他内容（尤其是旧对话记录 `codex_thread_dialog.md`，里面有明文密钥）。
